# Turkwerk V6 Share Preview

This repository publishes the V6 review site through GitHub Pages.

Recommended share entry point: `review.html`.

Search-engine controls:
- page-level `noindex,nofollow,noarchive,nosnippet,noimageindex`
- `robots.txt` with `Disallow: /`

This is link-private, not authentication-private. Anyone with the URL can view it.
